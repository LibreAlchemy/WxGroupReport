## 🤖 Agent 开发前必读

```
1. 先读「需求清单」→ docs/开发/需求清单/
   了解要做什么、验收标准

2. 再读「问题排查」→ docs/开发/问题排查/
   了解历史踩坑，避免重复犯错

3. 然后读「系分」→ docs/技术/系分/
   了解技术方案
```

## 📁 目录结构

```
docs/
├── 产品/                 # 产品文档
│   ├── BRD/             # 业务需求 (业务方)
│   ├── PRD/             # 产品需求 (@莫)
│   └── 评审记录/
│
├── 技术/                 # 技术文档
│   ├── 系分/            # 技术设计 (@Kyle)
│   ├── 技术文档/        # 实现细节
│   ├── API文档/         # 接口文档
│   └── 评审记录/
│
├── 开发/                 # ⭐ 开发过程文档
│   ├── 需求清单/        # ⭐ 待开发任务
│   ├── 已实现功能/      # 完成记录
│   └── 问题排查/        # ⭐ 踩坑记录
│
├── 测试/                 # 测试文档
│   ├── 测试分析/        # 测试策略 (@seasyec)
│   ├── 测试用例/        # 用例详情
│   └── 测试报告/        # 测试结果
│
├── templates/            # 所有模板
└── 归档/                 # 过期文档
```
