## 1. 项目概况

### 1.1 项目背景

借助 AI 技术做一个群聊记录分析工具，可按固定时间段：识别低活跃度和低质量成员（下面简称低质成员）、提取有价值的内容，整合形成周期报告（文本形式）。旨在通过该工具，优化伸手党，提升群聊内容质量，建设高价值密度的交流氛围。

### 1.2 用户对象

* **核心用户**：微信群群主、群管理员。
* **受益用户**：希望获取高质量内容的群成员。

### 1.3 产品定位

一款面向微信群管理员的 **AI 辅助分析工具**，定位为「群聊质量管理助手」。它不直接干涉群聊，而是通过数据分析辅助管理决策。

### 1.4 核心目标

1. **自动识别**：精准识别低活跃度和低质量（如纯表情包、无意义水群）成员。
2. **智能提取**：从海量聊天记录中提取高价值内容（技术文章、开源项目、精彩观点、工作机会）。
3. **周期报告**：定期生成文本报告，在终端输出，直观展示群聊健康度。
4. **辅助决策**：提供基于数据的成员管理建议（如清退名单、活跃度提醒）。

## 3. 功能详解

### 3.1 模块一：数据采集

| ID | 功能点 | 优先级 | 描述 |
| :--- | :--- | :--- | :--- |
| F1.1 | 聊天记录导入 | P0 | 支持导入微信群聊天记录文件，自动进行处理。 |
| F1.2 | 成员信息解析 | P0 | 自动识别发言人昵称、发言时间、消息内容。 |
| F1.3 | 白名单管理 | P1 | 支持导入/编辑白名单，白名单成员豁免考核。 |
| F1.4 | 周期配置 | P1 | 支持配置统计周期的起止时间。 |

**详细说明：**

* **F1.1 处理流程**：输入聊天记录文件 -> 解析消息结构 -> 提取发言人/时间/内容 -> 输出结构化消息列表。
* **F1.3 白名单规则**：
  * **输入格式**：支持简单的文本列表（如下所示）。

        ```
        # Top3 活跃成员
        张三
        李四
        王五

        # 贡献成员
        赵六
        钱七
        ```

  * **豁免权**：白名单成员不参与低质判定，但仍参与活跃度排名。

### 3.2 模块二：AI 分析

| ID | 功能点 | 优先级 | 描述 |
| :--- | :--- | :--- | :--- |
| F2.1 | 消息评分 | P0 | 采用“脚本基础分+AI加分”的混合模式进行评估。 |
| F2.2 | 成员画像 | P0 | 计算成员平均分、发言数、内容分类统计。 |
| F2.3 | 内容分类 | P0 | 识别链接类型、金句、机会分享等。 |
| F2.4 | 隐私过滤 | P0 | 过滤简历、个人信息等隐私内容。 |

**F2.1 评分体系：**

为保证评分的稳定性，系统采用 **脚本计算 + AI 综合评判** 的混合模式，最终计算该成员所有消息的平均分。

1. **脚本计算基础分**：
    * 每条有效消息赋予一个默认基础分（例如 60 分）。
    * 通过脚本规则进行硬性扣分（如：单字回复、纯表情包、黑名单关键词等直接降为 0 分或低分）。

2. **AI 综合评判 (Prompt 加分)**：
    * 将经过初筛的消息提交给 AI，AI 根据设定的 Prompt 对消息价值进行判断。
    * AI 不直接进行复杂的数学运算，而是基于内容价值给出 **加分建议**（如：+10, +20）。

**AI 加分参考维度：**

| 维度 | 说明 | 正向示例 (加分项) |
| :--- | :--- | :--- |
| 信息密度 | 消息是否包含实质性信息、观点、知识或资源分享 | (+)技术分享，干货满满 |
| 互动价值 | 是否推进话题讨论、回应他人问题或提出有价值的追问 | (+)建设性回复，引发思考 |
| 知识贡献 | 是否包含技术见解、经验总结、原创思考等内容 | (+)独到见解，经验之谈 |

**低质成员判定标准：**

* **零发言**：周期内无任何发言。
* **低质量**：周期内平均分 < 60分 (或根据实际基础分设定阈值)。

### 3.3 模块三：报告生成

| ID | 功能点 | 优先级 | 描述 |
| :--- | :--- | :--- | :--- |
| F3.1 | 活跃度排行 | P0 | 生成发言数 Top10 排行榜。 |
| F3.2 | 精彩内容提取 | P0 | 智能提取四类高价值内容并格式化展示。 |
| F3.3 | 低质成员名单 | P0 | 生成低质成员列表（不排序）。 |
| F3.4 | 文本报告输出 | P0 | 终端输出文本报告，支持导出 Markdown/TXT。 |

**F3.2 精彩内容分类逻辑：**

| 类型 | 识别规则 | 展示格式 |
| :--- | :--- | :--- | :--- |
| **公众号/技术文章** | 识别微信公众号、博客链接 | `公众号文章 <url> @发言人` |
| **GitHub/代码仓库** | 识别 github/gitlab 等链接 | `Github 项目 <url> @发言人` |
| **原创见解/金句** | AI 判定为精辟观点 | 原文摘录 + @发言人 |
| **机会分享** | 识别招聘、合作信息 | `机会分享 <摘要> @发言人` |
*注：列表按时间倒序排列；只展示原始链接，不抓取网页内容。*

**F3.4 报告输出形式：**

系统在终端（Console）直接输出结构化的文本报告，并支持保存为本地文件（如 `report_20260203.md` 或 `.txt`）。

**报告结构包含：**

1. **Header**: 统计周期时间说明。
2. **Section A**: 成员活跃度排行榜 (Top10)。
3. **Section B**: 本期精彩内容 (上述四类)。
4. **Section C**: 低质成员名单。

### 3.4 模块四：辅助决策 (Decision Support)

| ID | 功能点 | 优先级 | 描述 |
| :--- | :--- | :--- | :--- |
| F4.1 | 提醒文本生成 | P1 | 生成针对不同类型低质成员的提醒文本。 |
| F4.2 | 清退名单生成 | P0 | 生成待清退成员详细名单供管理员审核。 |
| F4.3 | 名单编辑 | P1 | 支持手动移除误判成员。 |
| F4.4 | 历史报告管理 | P1 | 支持查看和管理历史周期的分析报告。 |

**F4.1 提醒模板：**

```
@成员A [零发言] 本周期内未有任何发言记录，请积极参与群讨论...
@成员B [低质量] 你的发言以表情包为主，建议分享有价值的观点...
@成员C [低频次] 偶尔参与不错，建议增加活跃度...
```

**F4.2 清退名单字段：**

* 包含：成员昵称、周期内发言数、AI评分 (0-10)、严重程度 (零发言/低发言/低质量)。
* 排序：按严重程度降序（零发言 → 低发言 → 低质量）。
