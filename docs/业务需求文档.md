# 需求描述
借助 AI 技术做一个群聊记录分析工具，可按固定时间段：识别低活跃度和低质量成员（下面简称低质成员）、提取有价值的内容，整合形成周期报告（图片或链接形式）。旨在通过该工具，优化伸手党，提升群聊内容质量，建设高价值密度的交流氛围。

## 低质成员定义
在固定周期时间内：
- 没有任何发言记录的成员
- 只发表过低质量内容（表情、口水话、广告）

## 周期报告内容
- 统计周期时间
- 成员活跃度排行榜
- 本期精彩内容（公众号链接、文章链接、Github 链接、名言金句）
- 低质成员名单（不排序）

## 业务流程
- 统计周期结束前一周，群管理员使用工具生成报告，对低质成员进行手动群内提醒（提醒内容由工具提供）。
- 统计周期结束时，群管理员使用工具生成报告，对依然低质的成员进行清退。项目组成员 Review 本期报告， double check 检查是否存在数据问题，如有误则应提供可以二次修改的方法，若无误则在群里公开报告。
- 报告归档和复查，可以考虑上传到群文件留痕。

## 白名单机制
应该设计一个白名单奖励机制，对 Top 3 活跃成员、以及对群建有贡献的成员列入其中，豁免 N 个月（N≥1）。

## 隐私保护
报告内不得包含任何隐私内容，包括群成员上传的简历、个人信息等。
