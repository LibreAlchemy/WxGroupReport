# 需求描述

借助 AI 技术做一个群聊记录分析工具，可按固定时间段：识别低活跃度和低质量成员（下面简称低质成员）、提取有价值的内容，整合形成周期报告（图片或链接形式）。旨在通过该工具，优化伸手党，提升群聊内容质量，建设高价值密度的交流氛围。

---

## 低质成员定义

在固定周期时间内：
- 没有任何发言记录的成员
- 只发表过低质量内容（表情、口水话、广告）

### AI语义分析评分机制

低质成员的判定采用AI语义分析，对成员在统计周期内的所有消息进行综合评分，评分维度包括：

| 维度 | 说明 |
|------|------|
| 信息密度 | 消息是否包含实质性信息、观点、知识或资源分享 |
| 互动价值 | 是否推进话题讨论、回应他人问题或提出有价值的追问 |
| 知识贡献 | 是否包含技术见解、经验总结、原创思考等内容 |
| 内容完整度 | 消息长度、完整性，拒绝单字/纯表情/无意义回复 |

每条消息AI评分范围为0-10分，周期结束后计算成员平均分。平均分低于3分者，判定为低质成员。纯表情包、单字回复、刷屏式重复内容将直接计0分。

---

## 周期报告内容

- 统计周期时间
- 成员活跃度排行榜（发言数前10）
- 本期精彩内容（公众号链接、文章链接、Github 链接、名言金句）
- 低质成员名单（不排序）

### 精彩内容提取标准

报告"精彩内容"板块包含以下四类内容，由AI自动识别提取：

1. **公众号/技术文章链接**：展示格式为 `公众号文章 <url> @发言人`
2. **GitHub/代码仓库链接**：展示格式为 `Github 项目 <url> @发言人`
3. **原创见解/金句**：AI判断为精辟观点、经验总结、有启发性的发言，直接摘录原文并标注发言人
4. **机会分享**：展示格式为 `机会分享 <内容摘要> @发言人`

内容按时间倒序排列（最新发布的在前），每类最多展示10条。链接类内容不抓取目标网页内容，直接展示原始链接。

## 业务流程

### 1. 周期提醒阶段

统计周期结束前一周，群管理员使用工具生成提醒内容：

工具生成一条包含所有低质成员提醒的文本，格式如下：

```
@成员A [零发言] 本周期内未有任何发言记录，请积极参与群讨论...
@成员B [低质量] 你的发言以表情包为主，建议分享有价值的观点...
@成员C [低频次] 偶尔参与不错，建议增加活跃度...
```

管理员复制文本，可编辑调整后在群内一次性发送。

### 2. 周期结算阶段

统计周期结束时：
- 群管理员使用工具生成报告，对依然低质的成员进行清退
- 项目组成员 Review 本期报告，double check 检查是否存在数据问题
- 如有误判，可手动从名单中移除该成员
- 若无误则在群里公开报告，然后执行清退

### 3. 成员清退机制

采用纯手动方式：

1. 工具生成待清退成员名单，包含：成员昵称、周期内发言数、AI评分
2. 名单按严重程度排序（零发言 → 低发言 → 低质量）
3. 管理员在微信客户端内手动移除成员

---

## 白名单机制

管理员使用工具时可附带白名单，名单内的成员豁免考核。文本格式示例：

```
# Top3 活跃成员（豁免1个月）
张三
李四
王五

# 贡献成员（需注明豁免时长）
赵六 3个月
钱七 6个月
```

白名单成员在指定豁免时长内不计入低质成员名单，豁免期结束后恢复正常考核。

---

## 报告呈现形式

周期报告同时生成长图和网页链接两种格式：

| 格式 | 用途 | 说明 |
|------|------|------|
| 长图 | 群内直接发送 | 精美排版，信息一目了然，适合快速浏览 |
| 网页链接 | 详细查看 | HTML页面，支持交互查看详情 |

**报告内容板块：**
1. 统计周期时间
2. 成员活跃度排行榜（发言数前10）
3. 本期精彩内容（公众号文章、Github项目、原创见解、机会分享）
4. 低质成员名单

长图和网页内容保持一致，管理员根据场景选择使用。

---

## 隐私保护

报告内不得包含任何隐私内容，包括群成员上传的简历、个人信息等。
