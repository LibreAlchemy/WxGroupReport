## 1. 测试范围

### 测试目标

- 目标1: 验证 AI 评分模块 System Prompt 的逻辑符合度，确保评分逻辑符合“基础分 + 加分项 - 扣分项”原则。
- 目标2: 确保“脏数据”（无意义内容、水贴）被有效拦截并判定为低分或 0 分。
- 目标3: 验证高价值内容（技术分享、深度见解等）能够根据 PRD 权重获得合理的加分。
- 目标4: 验证 AI 输出格式严格遵循指定的 JSON 结构。

### 包含范围

- 功能测试: AI 评分逻辑判定（加分项、扣分项、一票否决）。
- 提示词测试: System Prompt 的指令遵循能力。

### 不包含范围

- 数据预处理: 原始消息的清洗与格式化脚本（由预处理脚本测试负责）。
- 报告生成: 基于评分结果生成最终报告的逻辑。

## 2. 测试策略

| 测试类型 | 覆盖范围 | 执行方式 |
|----------|----------|----------|
| 提示词测试 | System Prompt 逻辑边界 | 自动化 (Prompt 评测) |
| 功能测试 | 评分权重对齐 (误差 ±5分) | 自动化/半自动化 |
| 健壮性测试 | 各种极端输入 (单字、Emoji、长文本) | 自动化 |

## 4. 测试数据

### Mock 数据

```json
{
  "test_data": [
    { "input": "666", "expected_category": "water", "expected_score": 0 },
    { "input": "推荐大家试试 ijson 这个库...", "expected_category": "tech", "expected_score": 90 }
  ]
}
```

### 边界条件

| 场景 | 边界值 | 预期行为 |
|------|--------|----------|
| 无意义单字 | "1", "6", "🐮" | 触发一票否决，返回 0 分 |
| 极致高质量 | 包含代码、链接、见解 | 接近或达到 100 分上限 |
| 情绪化闲聊 | "sb", "头疼" | 触发低分判定，降权至 40-55 分 |
