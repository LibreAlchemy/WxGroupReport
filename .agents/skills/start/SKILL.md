# 技能：start

## 概述

这是一个组合技能，用于引导 Agent 自动按顺序执行微信群聊记录的完整分析流水线。

## 工作流

触发本技能后，按顺序执行：

1. **import-chat-data**
2. **analyze-messages**
3. **generate-report**
4. **refine-report**

## 使用约束

- **自动串行执行**：每一步成功后自动进入下一步，除非出现关键错误。
- **进度同步**：开始每个子技能前，向用户简短同步当前阶段。
- **环境约束**：禁止读取 `.env` 文件，脚本运行时通过环境变量加载配置。

## 触发示例

- “开始分析”
- “生成报告”
- “分析这个群聊”
- “跑完整流程”
